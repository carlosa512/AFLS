# Mail pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An interim head coach keeps his coordinator job; the owner writes a real letter when our head coach is let
go; other clubs' firings come as one weekly roundup; mail from other clubs shows their colours; SNN and the director
stop repeating each other on trades.

**Architecture:** Engine changes in `coaching.ts` (one optional `Coach.actingAs` field and a `coordinatorOf` helper
every coordinator read goes through), `leadership.ts` (the letter, stored in the event's existing `privateText`),
`inbox.ts` / `tradeNews.ts` (grouping, notes, one new optional `InboxMessage.fromTeamId`). UI in `Inbox.tsx`,
`mail.tsx`, `Coaches.tsx`. One save bump (v47) carries both new fields.

**Tech Stack:** TypeScript, React, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-26-mail-pass-design.md`

## Global Constraints

- Engine: no `Math.random`; any randomness on a seeded `Rng`. None is needed here.
- `League` stays plain JSON. `SAVE_VERSION` 46 → 47 in `generate.ts`, one `if (league.version < 47)` block in
  `migrate.ts`.
- Fog of war: mail and screens use only what the user can see: our own players' trade status, offers made to us,
  public results. Never `player.ratings`, interest records about our players, or another club's private text.
- Salaries are thousands of dollars; format money with the inbox's existing money helper (the one that prints
  `$5.58M`), never by hand.
- Each sender keeps its voice (`CLAUDE.md`): the owner direct and short, the director analytical, SNN neutral.
- `npm run format` before each commit. Run `npm run typecheck` and the touched test files; Task 1 also runs
  `npm run sim -- 10` and `npm run careers` (development and play read coordinators).
- Commits end with the session's attribution lines.

## Review Focus

1. **The user hires a coordinator into a chair the interim covers.** Expect the new hire to take the chair and
   `actingAs` to clear, so two people never run one side. (Test in Task 1.)
2. **An interim from the market, not from the staff.** Expect no `actingAs`, the empty coordinator chair filled as
   today, and the owner's letter not claiming he "keeps running" anything. (Tests in Tasks 1 and 2.)
3. **A team colour too light or too dark for its initials.** Expect readable text on every one of the 32 teams' primary
   colours. (Test in Task 4.)
4. **Old saves that already filed the single firing mails, or the old offer mail.** Expect no duplicate after the
   roundup ships and the old offers coloured by the backfill. (Tests in Tasks 3 and 4.)
5. **Two trades between the same two clubs in one week.** Expect each director line to get the right note, not the
   first deal's twice. (Test in Task 5.)
