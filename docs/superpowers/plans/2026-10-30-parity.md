# Parity: any given Sunday Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Games decided by team gaps about as often as the NFL's: each team brings a hidden form to each game, and only
if that isn't enough, a new league starts with narrower gaps.

**Architecture:** A pure draw per team per game (`teamDay`, its own `Rng` stream off the game's seed) goes into the
lineup's knocks overlay next to the mood edge, so every contest reads it and nothing else in the game moves. The sim
check gains three parity lines that fail like any other line; careers reports the long-run win spread.

**Tech Stack:** TypeScript, Vitest, tsx scripts (`npm run sim`, `npm run careers`, `npm run audit`).

**Spec:** `docs/superpowers/specs/2026-10-30-parity-design.md`

## Global Constraints

- Branch `claude/gallant-ramanujan-rzydgt-engine`; one PR to main. Never force push.
- Vitest always with `--maxWorkers=2` (more runs the container out of memory).
- Never loosen a range to get green. If a parity line or any existing line can't be met, stop and tell the owner why.
- No `Math.random`: the draw comes from `new Rng(...)` on its own stream, so no other draw in a game moves.
- Hidden: no screen, recap, mail or report shows it. No new words.
- Nothing stored: `League` keeps its shape, no `SAVE_VERSION` bump, no migration.
- How one play is decided, running-back workloads and injuries stay untouched (spec, Out of scope).
- In code, the spec's "form" is called the team's **day** (`teamDay`, `DAY_SD`): "form" already means a player's
  form in this engine (`formFor`, `recordForm`, `GameResult.form`).
- Measuring and tuning run `npm run sim -- 60` (about 4 minutes, run in the background). CI keeps running 30.
- `npm run format` before every commit. Version 0.2.27 (a fix: last number), changelog entry, MVP line.

## Review Focus

1. **A lineup rebuilt mid-game after an injury** must keep the team's day, not drop it or draw a new one → Task 2's
   spy test on every `buildLineup` call a game makes (`GameSim` passes the same `days[side]` at both call sites).
2. **A fill-in playing out of position on a good or bad day** must carry both knocks (position knock less the day),
   not one replacing the other → Task 2's lineup test.
3. **Paired replays** (audit, size levers, quirk effects, weather) replay a game with `options.seed`: both runs must
   draw the same day, or a lever's effect drowns in the day's noise → Task 2's test that `options.seed` decides it.
4. **Kickers and punters** read the day too (every contest): the sim's fgPct and punts lines must hold → Task 3 reads
   them over 60 seasons.
5. **A lineup read outside a game** (opposition report, previews, tests) passes no day and sees none → Task 2's test
   that `buildLineup` without a day leaves knocks as before.

### Task 2: A team's day

**Files:**
- Modify: `src/engine/match/lineup.ts` (`DAY_SD`, `teamDay`, `buildLineup`'s `day` parameter, `Lineup.knocks` doc)
- Modify: `src/engine/match/gameSim.ts:88-101` (`SimOptions.days`), `:570-596` (draw both days), `:906` (rebuild)
- Test: `src/engine/parity.test.ts` (new)

**Interfaces:**
- Produces:
  - `export const DAY_SD = 0.45` in `match/lineup.ts` (rating points; Task 3 may change the value, not the name)
  - `export function teamDay(gameSeed: string, teamId: number): number` → `new Rng(\`${gameSeed}:day:${teamId}\`)
    .normal(0, DAY_SD)`. `gameSeed` is the game's own: `options.seed ?? \`${league.seed}:${season}:${gameId}\``.
  - `buildLineup(league, team, out?, game?, mean?, day = 0): Lineup`: every man in the lineup's slots gets
    `knock = (position knock if out of position) − mood edge − day`; a zero knock is deleted as today.
  - `SimOptions.days?: [home: number, away: number]`: overrides the draw (tests), like `weather` and `crew`.
  - `GameSim` keeps `private days: [number, number]` and passes `this.days[side]` at both `buildLineup` call sites.

- [ ] **Step 1: Write the failing tests**

Copy `moraleEffects.test.ts`'s spy (`vi.mock('./match/lineup', …)` wrapping `buildLineup`), recording
`[team.id, args[5]]` for every lineup the sim builds; dynamic imports after it, as there.

```ts
describe("a team's day (parity)", () => {
  it('is drawn from the game seed and the team alone', () => {
    expect(teamDay('s:2026:7', 3)).toBe(teamDay('s:2026:7', 3));
    expect(teamDay('s:2026:7', 3)).not.toBe(teamDay('s:2026:7', 4));
    expect(teamDay('s:2026:7', 3)).not.toBe(teamDay('s:2026:8', 3));
  });

  it('averages zero, DAY_SD either side', () => {
    const d = Array.from({ length: 4000 }, (_, i) => teamDay(`p:${i}`, i % 32));
    const mean = d.reduce((a, b) => a + b, 0) / d.length;
    const sd = Math.sqrt(d.reduce((a, b) => a + (b - mean) ** 2, 0) / d.length);
    expect(Math.abs(mean)).toBeLessThan(0.03);
    expect(sd / DAY_SD).toBeGreaterThan(0.95);
    expect(sd / DAY_SD).toBeLessThan(1.05);
  });

  it('lifts every man in the lineup, a fill-in on top of his position knock', () => {
    const l = createLeague({ seed: 'parity-day' });
    const team = l.teams[0];
    // Put a safety at corner so one man plays out of position.
    const fill = l.players[team.depthChart.S[0]];
    team.depthChart.CB = [fill.id, ...team.depthChart.CB.filter((id) => id !== fill.id)];
    const plain = buildLineup(l, team);
    const day = buildLineup(l, team, new Set(), undefined, undefined, 1);
    for (const p of slotted(day)) expect(day.knocks.get(p.id)).toBeCloseTo((plain.knocks.get(p.id) ?? 0) - 1, 9);
    expect(day.knocks.get(fill.id)).toBeCloseTo(knockFor(fill, 'CB') - 1, 9);
    const qb = day.qb;
    const base = skill(qb, 'pocketPresence');
    const prev = useKnocks(day.knocks);
    expect(skill(qb, 'pocketPresence') - base).toBeCloseTo(1, 9);
    useKnocks(prev);
  });

  it('is no edge when no day is passed', () => {
    const l = createLeague({ seed: 'parity-day' });
    const team = l.teams[0];
    expect([...buildLineup(l, team, new Set(), undefined, undefined, 0).knocks]).toEqual([
      ...buildLineup(l, team).knocks,
    ]);
  });

  it('decides some games: a sharp home day against a flat road day moves the margin', () => {
    const margin = (days: [number, number]) => {
      let sum = 0;
      for (let i = 0; i < 40; i++) {
        const l = createLeague({ seed: 'parity-day' });
        const r = simulateGame(l, l.games[0], { seed: `m:${i}`, days });
        sum += r.homeScore - r.awayScore;
      }
      return sum / 40;
    };
    expect(margin([0.5, -0.5]) - margin([0, 0])).toBeGreaterThan(3);
  }, 120_000);

  it('hands each lineup its own day, the rebuild after an injury too, and replays it from the seed', () => {
    const l = createLeague({ seed: 'parity-day' });
    let rebuilt = 0;
    for (const g of l.games.filter((x) => x.week <= 3)) {
      calls.length = 0;
      const base = `${l.seed}:${g.season}:${g.id}`;
      simulateGame(l, g);
      for (const [teamId, day] of calls) expect(day).toBe(teamDay(base, teamId));
      if (calls.length > 2) rebuilt++;
    }
    expect(rebuilt).toBeGreaterThan(0);
    const g = l.games[0];
    expect(simulateGame(l, g, { seed: 'again' })).toEqual(simulateGame(l, g, { seed: 'again' }));
  }, 60_000);
});
```

`buildLineup` puts in `slots`); read `Lineup`'s fields for them. The rebuild test plays games without changing the
league (as the morale test's does), so each game's lineups are its own.
